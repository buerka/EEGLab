新增图片先放入 `frontend/public/temp/`，整理命名后移至对应图片目录，同步本清单、图库 TOML 和相关页面。公开静态单个文件不能超过 25 MB，根目录部署检查会验证；不得将密钥、实时数据库或后端种子放入 `public`。
